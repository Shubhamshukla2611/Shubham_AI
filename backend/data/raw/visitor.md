# 📱 Visitor Management System (Android App)

A mobile-based Visitor Management System developed using React Native (Expo) to replace traditional manual entry processes with a secure and digital solution.

## 🚀 Features
- 🔐 User Authentication (Login / Signup)
- 📝 Visitor Entry Management
- 📊 Real-time Visitor Status Tracking (Pending / Approved / Rejected)
- 🔄 Approval Workflow System
- 📡 REST API Integration for backend communication
- 📦 Standalone APK build using Expo EAS (No Expo Go required)

## 🛠️ Tech Stack
- React Native (Expo)
- Node.js (Backend APIs)
- Firebase (Optional Integration)
- REST APIs & JSON Handling

## ⚙️ How It Works
1. Guard enters visitor details through the app  
2. Data is sent to backend via REST APIs  
3. Visitor status is tracked and updated in real-time  
4. System replaces manual entry logs with a digital workflow  

## 📦 Build
The app is built as a standalone Android APK using Expo EAS, ensuring smooth performance without requiring Expo Go.

## 🎯 Purpose
To provide a secure, efficient, and scalable solution for managing visitor entries in controlled environments such as offices or government facilities.
